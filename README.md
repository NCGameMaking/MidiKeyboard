# MidiKeyboard
Music week is circuits that turn voltage into sound.


This MidiKeyboard is 6+ part keypad that will turn voltage into sound. 
I designed this for the Week 3 Half-Life programme. A YSWS hosted a hackclub to teach kids how to become pro at hardware.

## Features
- 1 Rotary Encoder
- 2 Bourns slides potentiometers
- 3 Kailh Choc Low-profile keys
- 3 Neopixels that go under the Keys that will light up
- 7 Capacitive-Touch Keys
This is all powered by the none other Waveshare ESP32-S3-ZERO
